# Bacheca digitale T.C. Vialar

Bacheca a schermo intero per la TV della segreteria.

- Indirizzo da aprire sulla TV: https://tennisclubvialar.github.io/bacheca/
- Contenuti fissi (slide, prezzi, avvisi): blocco `BACHECA` in `index.html`.
- Post Instagram: scaricati ogni ora dal workflow "Aggiorna post Instagram" in `instagram/`.
- La pagina controlla ogni 5 minuti se qualcosa è cambiato e si ricarica da sola.
